# **ПЛАТФОРМА ПОДБОРА И ОЦЕНКИ РОБОТИЗИРОВАННЫХ РЕШЕНИЙ (СППР v1.0)**

Интерактивная экспертно-аналитическая система для технико-экономического обоснования (ТЭО), имитационного моделирования и спектрального анализа узких мест при внедрении роботизированных комплексных решений (AMR, AGV, FMR, курьерские роботы) на складах, в аэропортах и медицинских учреждениях.

## **2. МАТЕМАТИЧЕСКАЯ И АЛГОРИТМИЧЕСКАЯ МЕТОДОЛОГИЯ**

Платформа опирается на строгие математические модели теории очередей, финансового анализа и спектральной теории графов:

### **2.1. Финансово-экономический расчет (3-way Financial Modeling & What-If)**
1. **Коэффициент готовности робота ($k_{\text{avail}}$):**
   $$k_{\text{avail}} = \frac{T_{\text{runtime}}}{T_{\text{runtime}} + T_{\text{charge}}}$$
2. **Потребный размер флота ($N_{\text{fleet}}$):**
   $$N_{\text{fleet}} = \left\lceil \frac{Q_{\text{target}}}{P_{\text{single}} \cdot k_{\text{avail}}} \right\rceil$$
3. **Совокупная стоимость владения (5-Year TCO):**
   $$\text{TCO}_{\text{buy}} = \text{CAPEX} + \sum_{t=1}^{5} \frac{\text{OPEX}_t}{(1 + r)^t}$$
   *(включая 7% ежегодную индексацию ФОТ надзорного персонала и резервный буфер замены батарей на 3–4 год).*

### **2.2. Спектральный анализ узких мест графа топологии (Spectral Graph Theory)**
* **Матрица Лапласа графа ($L = D - A$):**
  Анализирует связность топологического графа объекта.
* **Алгебраическая связность ($\lambda_2$ - Число Фидлера):**
  Рассчитывается методом сдвинутых степенных итераций. Определяет общую пропускную способность транспортной сети:
  - $\lambda_2 \ge 0.35$ — **OPTIMAL** (оптимальная топология, минимальный риск пробок);
  - $0.15 \le \lambda_2 < 0.35$ — **MODERATE** (умеренный риск локальных заторов);
  - $\lambda_2 < 0.15$ — **CRITICAL** (обнаружено узкое горлышко, требуются альтернативные проезды).
* **Критический вектор Фидлера ($v_2$):**
  Узлы с $|v_2(i)| < 0.05$ автоматически идентифицируются как потенциальные точки заторов (Bottleneck Cut-Sets).

### **2.3. Имитационное моделирование (Discrete-Event FSM Simulation & Gordon-Newell Networks)**
* Каждая единица техники моделируется как автономный агент с конечным автоматом состояний (`IDLE`, `MOVING_TO_PICKUP`, `LOADING`, `TRANSPORTING`, `UNLOADING`, `NEEDS_CHARGE`, `CHARGING`).
* Маршрутизация агентов выполняется по алгоритму Дейкстры с динамическим контролем дистанции безопасности (Safe Braking Distance = 25px) и приоритетной очередностью на зарядных станциях (SoC < 20%).
